# 研レンズ (KenLens) プライバシーポリシー

発効日: 2026年6月10日

本文書が正本です。ランディングページ (LP) のプライバシーページは本文書と同等の内容を掲載します。英語版は `privacy-policy.en.md` を参照してください。

研レンズは、researchmap.jp の研究者ページに被引用数・オープンアクセス (OA) 状況・DOI の情報を表示する Chrome 拡張機能です。研究評価ではなく、公開メタデータの可視化・整備支援です。

## 1. 収集しない情報

研レンズは以下を一切行いません。

- **アクセス解析 (アナリティクス) なし**: Google Analytics 等の解析ツールは組み込んでいません。
- **アカウントなし**: 利用登録・ログインは存在せず、利用者を識別する ID も発行しません。
- **閲覧履歴の収集なし**: 閲覧したページの記録を開発者や第三者に送信することはありません。
- **開発者サーバーなし**: 開発者が運用するデータ収集サーバーは存在しません (後述のリモート設定 JSON は GitHub Pages 上の静的ファイルの取得のみです)。

## 2. ブラウザの外部に送信される情報

拡張機能の動作に必要な最小限の情報のみが、以下の公的・学術 API と静的設定ファイルの配信元に送信またはリクエストされます。

| 送信先 | 送信される情報 | 目的 |
| --- | --- | --- |
| `api.researchmap.jp` | 閲覧中の研究者ページのパーマリンク (URL 末尾の識別子)。整備レポートでも同じパーマリンクのみ | 公開業績一覧の取得。整備レポートでは、公開されている論文・MISC・書籍等・講演/口頭発表の一覧を突合のため取得 |
| `api.openalex.org` | 論文の DOI (および任意設定の OpenAlex API キー)。整備レポートでは、これらの DOI から導かれた OpenAlex 著者レコード ID | 被引用数・OA 状況の取得 (`GET /works/doi:{DOI}`)、整備レポートでの著者論文一覧の照会 |
| `api.crossref.org` | 論文の DOI。DOI 未登録の欧文論文では、論文タイトルと開発者の連絡先メールアドレスのみ | 被引用数の取得 (フォールバック) と DOI 候補の照合 (`query.bibliographic=タイトル`, `mailto=連絡先`) |
| `api.unpaywall.org` | 論文の DOI | OA 状況の取得 (Crossref 経路のときのみ) |
| `r-okauchi.github.io` | 個人情報・閲覧情報は含まれません (静的 JSON `config.json` の取得のみ) | researchmap API 利用を停止するための動作設定の確認。1 日 1 回程度 |

補足:

- Crossref へのタイトル照合は欧文 (ラテン文字) タイトルの論文のみ対象で、送信されるのは論文タイトルと開発者の連絡先メールアドレスのみです。出版年・著者姓はブラウザ内での照合判定にのみ使用され、Crossref には送信されません。
- 整備レポートに貼り付け・選択した BibTeX ファイルはブラウザ内でのみ処理され、外部に送信されることはありません。
- Crossref / Unpaywall へのリクエストには、API 提供者のガイドライン (polite pool) に従い、**開発者の**連絡先メールアドレスがパラメータとして付与されます。利用者のメールアドレスが送信されることはありません。
- リモート設定の取得は、開発者の GitHub Pages 上の静的ファイルを 1 日 1 回程度取得するものです。このリクエストに個人情報・閲覧情報は含まれません。
- これらの情報はいずれも researchmap 上で公開されている書誌メタデータであり、利用者個人に関する情報ではありません。
- 各 API へのリクエストはホストごとに自己制限されています (researchmap: 1 リクエスト/秒・並列 1、ほか)。

## 3. 利用目的

送信される情報は、以下の目的にのみ使用されます。

1. 閲覧中の研究者ページの公開業績一覧の取得
2. 各論文の被引用数・OA 状況・DOI 情報の取得と表示
3. DOI 未登録の論文に対する DOI 候補の提示 (プロフィール整備支援)

これら以外の目的 (広告、プロファイリング、第三者提供等) には一切使用しません。

## 4. ブラウザ内に保存される情報 (ローカルキャッシュ・設定)

すべてお使いのブラウザ内 (`chrome.storage`) にのみ保存され、開発者には送信されません。

- **APIレスポンスのキャッシュ** (`chrome.storage.local`):
  - researchmap 業績一覧: 24 時間
  - DOI ごとの外部データベース照合結果: 7 日間
  - タイトル→DOI 照合結果: 30 日間
  - 件数上限 (約 20,000 件) を超えた分と期限切れ分は毎日自動削除されます。設定画面の「キャッシュを消去」からいつでも全削除できます。
- **表示設定** (`chrome.storage.sync`): バッジ表示の ON/OFF、言語、動作モードなど。ブラウザのアカウント同期機能を有効にしている場合、お使いのブラウザベンダー (Google 等) の同期機構を通じて端末間で同期されます。開発者のサーバーは介在しません。
- **OpenAlex API キー (任意)** (`chrome.storage.local`): 設定した場合のみ保存されます。意図的に同期対象から外しており、この端末のローカルにのみ保存されます。送信先は `api.openalex.org` のみです。
- **サマリーカードの折りたたみ状態** (`chrome.storage.local`)。

拡張機能をアンインストールすると、これらの保存データはブラウザにより削除されます。

## 5. 権限について

| 権限 | 用途 |
| --- | --- |
| `storage` | 上記のキャッシュ・設定の保存 |
| `alarms` | 期限切れキャッシュの日次削除と、リモート設定 (障害時の運用フラグ) の日次確認 |
| `https://api.researchmap.jp/*` | 閲覧中の研究者の公開業績一覧の取得 |
| `https://api.openalex.org/*` | 被引用数・OA 状況の取得 |
| `https://api.crossref.org/*` | 被引用数の取得 (フォールバック) と DOI 候補の照合 |
| `https://api.unpaywall.org/*` | OA 状況の取得 (フォールバック) |
| `https://r-okauchi.github.io/*` | researchmap API 利用を停止するための動作設定の取得 |

コンテンツスクリプトは `https://researchmap.jp/*` でのみ動作します。それ以外のサイトでは一切動作せず、ページ内容にもアクセスしません。設定の「ページ内データのみ」モードを選択すると、外部データベースへの接続は行われません。

## 8. 変更について

本ポリシーを変更する場合は、本文書および LP のプライバシーページを更新し、発効日を改めます。送信される情報の種類や送信先が増えるなどの重要な変更は、拡張機能の更新情報 (ストアの更新ノートおよびリポジトリのリリースノート) で告知します。
